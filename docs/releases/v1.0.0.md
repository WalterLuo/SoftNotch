# SoftNotch 1.0.0

2026-10-27 · 应用版本 **1.0.0** · 构建号 **20261016.1** · **Apple Silicon / arm64**

这是当前 Sapphire 衍生 SoftNotch 的首个 GitHub 安装包。保留原生 SwiftUI / AppKit 刘海界面与公开源码实现，使用 SoftNotch 独立的应用身份和数据目录。

## 本版内容

- **日历重新展开回到今天**：每次重新打开刘海面板，按当前本地日期和时区选中今天；面板持续打开时，仍可浏览其他日期。
- **快捷截图**：截图按钮位于“钉在桌面”左侧。框选后写入剪贴板，可用 `Command + V` 粘贴，按 `Esc` 取消。
- **中英文设置**：默认简体中文，可切换 English。
- **独立应用身份**：主程序 `com.walterluo.softnotch`、辅助程序 `com.walterluo.softnotchHelper`，使用独立设置、文件目录与钥匙串服务。
- **现有集成**：保留音乐控制、日历、天气、文件暂存、窗口贴靠、蓝牙和电池状态等公开源码实现。上游自动更新、Google Analytics 和 Crashlytics 收集保持禁用。

## 下载与安装

- [SoftNotch-1.0.0-macOS-arm64.zip](https://github.com/WalterLuo/SoftNotch/releases/download/v1.0.0/SoftNotch-1.0.0-macOS-arm64.zip)：解压后包含 `SoftNotch.app`。
- [SHA256SUMS](https://github.com/WalterLuo/SoftNotch/releases/download/v1.0.0/SHA256SUMS)：安装包 SHA-256 校验值。

将两个文件放在同一目录，在该目录运行：

```sh
shasum -a 256 -c SHA256SUMS
```

确认校验通过后，退出正在运行的 SoftNotch，备份已有同名应用及数据，将解压得到的 `SoftNotch.app` 放入“应用程序”。首次启动按 macOS 提示和实际功能需要授予权限。电池温度及充电控制还需要允许 SoftNotch Helper 在后台运行。

安装包使用本地签名身份，**未经 Apple Developer ID 公证**。macOS 可能提示无法验证开发者，请在确认下载来源与校验结果后，按系统提供的安全提示操作。应用没有自动更新源，后续版本需手动下载和更换。

## 兼容与迁移

- 本包仅提供 Apple Silicon / arm64，未提供 Intel 安装包。
- 构建验证环境为 macOS 27.0.1、Xcode 27.1。工程部署目标为 macOS 14.6，但随附的 `MediaRemoteAdapter.framework` 声明最低 macOS 26.0；旧系统的媒体功能与整包运行情况尚未实机验证。
- 此前同名 SoftNotch 基于 boring.notch，当前版本基于 Sapphire。应用文件名相同，但数据身份和格式不同，**不会自动迁移旧版待办、偏好、文件暂存记录或 Sapphire 数据**。
- 旧版源码与说明保留在 [历史提交](https://github.com/WalterLuo/SoftNotch/tree/d1a4137b6c68f5faffbf1c5d2f7bbccf93bc13f2)。迁移与回退步骤见 [迁移说明](https://github.com/WalterLuo/SoftNotch/blob/v1.0.0/docs/MIGRATION.md)。

发布准备前，同源的本地 Release 构建与 22 项选定测试已经通过，覆盖独立身份、日历日期与可见性、文件拖拽剪贴板逻辑；构建复用了已有依赖缓存和 DerivedData。GitHub 自动静态检查也已通过。
