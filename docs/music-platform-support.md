# 网易云 / QQ 音乐及其他播放器

在设置 → 媒体 → 音乐来源选择 **自动识别（网易云 / QQ 音乐等）**。
旧版对应选项叫 **Now Playing**。Apple Music、Spotify 是专用来源，不会监听网易云。
保存值仍使用 `Now Playing`，现有设置不会被强行覆盖。

自动模式通过随项目附带的 MediaRemoteAdapter 读取 macOS 当前播放会话。
播放器必须向系统提供歌曲信息；这里没有加入网易云或 QQ 音乐的私有网络接口。
显示歌名、歌手、专辑、封面和进度；播放、暂停、切歌、拖动进度沿用系统媒体控制，
具体能力取决于当前播放器。多个 App 同时播放时，显示系统选中的当前媒体会话。
网易云和 QQ 音乐不提供本项目支持的应用内音量或收藏接口，因此不会启用这些能力。
如果系统兼容性检测失败，自动模式仍会按原有逻辑隐藏。

## 本次修复

- 将通用来源标注为自动识别，并在设置和引导中解释适用平台。
- 使用完整媒体快照，避免暂停/恢复等更新丢失封面，并正确处理元数据清空。
- 数据管道先按换行切分字节，再解码 JSON，避免中文 UTF-8 字符跨读取边界时丢失歌曲更新。
- 兼容增量更新，处理暂停/恢复时间基准、来源切换和带小数秒的时间戳。
- 切换来源时刷新收藏能力；无封面、无应用图标时清掉上一个来源的封面。


检查覆盖网易云歌曲信息、封面保持与清空、暂停/恢复、来源切换、时间戳、
