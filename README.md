# SoftNotch

由 Walterluo 制作提供。

版本：1.0.0 · 版本名称：噗噗噗💨

macOS 刘海面板，提供音乐控制、按日期管理的待办、截屏、文件暂存与隔空投送。

## 构建

使用 Xcode 打开 `boringNotch.xcodeproj`，选择 `boringNotch` scheme 构建。应用产物为 `SoftNotch.app`。

沿用原 bundle identifier 和数据目录，保留已有设置、待办与暂存记录。
